Nord Theme CSS

A lightweight CSS implementation of the Nord colour palette.

CDN Usage

<link rel="stylesheet"
href="https://crazyrag778.github.io/nord-theme-css/palettes/nord-main.css">

Example

body {
    background: var(--nord0);
    color: var(--nord6);
}

.button {
    background: var(--nord8);
}
